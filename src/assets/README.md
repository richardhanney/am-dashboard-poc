# Bundled world map

`world-countries.json` contains Natural Earth 1:110m country outlines, with English names only, coordinates rounded to three decimal places, and Antarctica omitted because it is outside the prototype map extent. No customer records or locations are included in this basemap asset.

- [Original dataset](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)
- [Natural Earth public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/)

Natural Earth permits personal, educational and commercial use without permission. The map credits Natural Earth. The bundled outlines let the prototype work without external map requests; they are generalised world geography, not street-level detail.
